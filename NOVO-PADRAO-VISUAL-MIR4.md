# Novo padrão visual MIR4 — interface completa

Alteração exclusivamente visual.

Foi aplicado o padrão dark fantasy oriental em:
- menu lateral principal;
- menu de categorias/módulos;
- topbar;
- HOME;
- cabeçalhos de páginas;
- cards e painéis;
- botões;
- formulários;
- tabelas;
- badges;
- menus internos de Configurações e STAFF;
- modais/drawers;
- calendário;
- notificações e avisos;
- barras de rolagem;
- responsividade do menu.

Não foram alterados:
- IDs;
- data attributes usados pela navegação;
- handlers;
- permissões;
- regras Firestore/Storage;
- Firebase;
- lógica funcional.

Firebase: NÃO precisa publicar regras para esta versão.
É necessário apenas publicar/atualizar os arquivos do site.
