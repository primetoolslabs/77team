77 TEAM MANAGER - V7.1 RECUPERAÇÃO DE PERSONAGENS

CAUSA CORRIGIDA:
A V7 carregava characters + attendance + payments + events usando Promise.all().
Se qualquer uma das 4 tabelas falhasse por RLS, TODO o carregamento era cancelado.
Por isso os Personagens podiam sumir mesmo continuando no Supabase.

AGORA:
- cada tabela carrega de forma independente;
- falha em Presenças não apaga Personagens;
- falha em Pagamentos não apaga Personagens;
- falha em Eventos não apaga Personagens;
- última lista válida de Personagens é preservada se houver erro temporário;
- RLS de characters é reparado.

PASSOS:
1. Supabase > SQL Editor.
2. Execute SUPABASE-V7.1-RECUPERAR-PERSONAGENS.sql.
3. Confira o resultado characters_total.
4. Publique esta versão.
5. CTRL+F5.

Para diagnóstico no Console:
await TeamManagerDiagnoseSupabaseCore()
