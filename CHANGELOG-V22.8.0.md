# 77 TEAM Manager V22.8.0 🟢 Stable

Base oficial: V22.7.3.

## Novidades
- Botão **Backup Presença** para DEV, Liderança e Staff.
- Botão **Resetar Presença** exclusivo para DEV e Liderança.
- Backup automático obrigatório antes de qualquer reset.
- Histórico permanente de backups por semana, com presentes, justificados, ausentes, total, responsável e data/hora.
- Download individual de cada backup em JSON.
- Nova coleção Firestore `presenceBackups`.
- Melhorias responsivas na área de Presença.

## Preservação
- Todos os módulos, telas, permissões e integrações existentes foram mantidos.
- Firebase Authentication, Firestore e Storage preservados.
- Nenhuma funcionalidade anterior foi removida.
